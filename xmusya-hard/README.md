# xmusya-hard

Хардкор с прогрессией по игровым дням — плагин-порт одноимённого датапака.
Paper/Leaf **Minecraft 26.3** (нужен JDK 25 для сборки).

Готовый файл: [`BuiltPlugins/xmusya-hard-1.1.8.jar`](BuiltPlugins/xmusya-hard-1.1.8.jar)

## Установка

1. Удалить/выключить старый датапак `<мир>/datapacks/xmusya-hard 26.3.zip`
   (иначе пак и плагин будут дублировать эффекты и мешать друг другу).
2. Скопировать `xmusya-hard-1.1.8.jar` в `<сервер>/plugins/.
3. Полностью перезапустить сервер (не `/reload`).
4. Исключить бота из всех проверок: `/tag <ник_бота> add bot`.
5. Открыть меню: `/xmh`.

## Команды

| Команда | Права | Что делает |
|---|---|---|
| `/xmh` | все | Меню: фаза, день, статистика, кнопки |
| `/xmh bar` | все | Личный тумблер боссбара (то же, что тег `hide_bossbar`) |
| `/xmh skip` | op | Пропустить один день |
| `/xmh reset` | op | Сброс к дню 0, фаза wood, барьер 650 |
| `/xmh pause` / `/xmh resume` | op | Пауза/продолжение фаз и счётчика дней |
| `/xmh bm start\|stop\|pause\|resume` | op | Управление Кровавой луной |
| `/xmh phase <name>` | op | Установить фазу: `wood, stone, iron, diamond, nether, golden_food, villagers, beacons, netherite, endgame` |
| `/xmh egg` | все | Привязать яйцо дракона (нужно держать в инвентаре) |
| `/xmh effect give <эффект\|hearts> <ник>` | все | Передать свой позитивный эффект или бонусное сердце другому игроку |
| `/xmh end status` | op | Статус крепости и рамок портала |
| `/xmh end locate` | op | Заново найти крепость (если не нашлась сама) |
| `/xmh end scan` | op | Пересканировать комнату портала |
| `/xmh end reset` | op | Сбросить рамки портала и пересканировать |
| `/xmh reload` | op | Перечитать `config.yml` на живом сервере |

Право `xmusyahard.admin` (по умолчанию op) открывает админ-панель в меню.

## Конфиг

`plugins/xmusya-hard/config.yml` — читается при старте и по `/xmh reload`.
Порядок фаз фиксирован:
`wood → stone → iron → diamond → nether → golden_food → villagers → beacons → netherite → endgame`.

Параметры каждой фазы (`phases.<key>`):

| Ключ | Смысл |
|---|---|
| `day` | день, с которого начинается фаза |
| `border` | размер барьера при переходе через `/xmh phase` |
| `name` / `short-name` | названия в чате/меню и в боссбаре |
| `limited-crafting` | геймрул `limited_crafting` в этой фазе |
| `natural-regeneration` | геймрул `natural_health_regeneration` |
| `trade` | разрешена ли торговля с жителями |
| `dimensions` | разрешённые измерения: `overworld`, `nether`, `end` |
| `forbidden-armor` | броня, которую нельзя носить — выбрасывается |
| `forbidden-tools` | инструменты/оружие — дают `mining_fatigue` + `weakness` |
| `forbidden-items` | предметы, выбрасываемые из инвентаря |
| `recipes` | рецепты, открывающиеся на этой фазе (дальше не отбираются) |

В `forbidden-armor`/`forbidden-tools` можно писать группы:
`iron`, `golden`, `diamond`, `netherite`, `stone`, `elytra` —
или точный id предмета (`minecraft:turtle_helmet`, `minecraft:trident`).
Неизвестный id → предупреждение в лог, фаза грузится без него.

Глобальные секции:

```yaml
border: {start: 650, mid1: 1250, mid2: 2500, daily: 100, max: 15000}
bloodmoon:
  interval: 10        # каждая N-я ночь
  mob-strength: 0     # amplifier: 0 = Сила I, 1 = II, -1 = без усиления
  mob-speed: 0
starter-buffs-until-day: 4   # Спешка I + Скорость I до этого дня включительно
```

Прогресс (день, фаза, статистика) хранится в `plugins/xmusya-hard/state.yml`,
энд-механики (крепость, рамки, баффы, сердца, проклятия) — в `end-state.yml`.

### Секция `end:` (энд-механики, 1.1.0)

```yaml
end:
  stronghold:
    min-radius: 5000      # крепость не ближе 5000 блоков от спавна
    max-radius: 8000
    disable-other-portals: true   # у всех остальных крепостей портал ломается
    search-border-size: 50000     # барьер на время первого поиска крепости (0 = не трогать)
    enabled: true                 # одна крепость ≥5000, порталы в остальных ломаются
  eyes:
    break-chance: 0.20    # шанс поломки ока
    glow-seconds: 10
    break-sound: "entity.lightning_bolt.thunder"   # "" = без звука
    break-sound-volume: 1.0
    break-sound-pitch: 1.0
  pearls:
    enderman-chance: 0.10            # 10% без Looting
    enderman-chance-looting: 0.20    # 20% с Looting III
    remove-from-barter: true
  blaze:
    no-build-radius: 12
    protect-explosions: true
    ghast-chance: 0.15
    ghast-max: 2
  portal:
    buff-hours: 24
    hearts-per-frames: 2
    items: [...]          # пул предметов для рамок
  cycle: {start-day: 100, interval-days: 50, reset-min: 1, reset-max: 4}
  protection: {curse-hours: 6, end-ban-hours: 6}
  outer-islands: {unlock-day: 80, max-distance: 450}
  dragon: {shield-cooldown-ms: 1800}
  void: {min-y: 0, pearls: 2, levitation-seconds: 10, slow-falling-seconds: 15}
  egg: {haste-amplifier: 1, speed-amplifier: 0}
```

Если секции `end:` нет (старый конфиг) — работают встроенные значения,
перечисленные выше.

## Что реализовано

- Честный счётчик дней: учитывает сон, ручной сдвиг времени, паузы.
- **Геймрулы и мировой барьер применяются во всех мирах** (оверворлд, Незер,
  Энд): геймрулы — через `execute in <измерение> run gamerule ...`, барьер —
  через `WorldBorder` каждого мира. В Java у каждого мира свои геймрулы/время.
- Авто-пауза через 30 сек без живых игроков (`advance_time`/`advance_weather` off).
- 10 фаз (по умолчанию): wood(0), stone(1), iron(5), diamond(10), nether(25),
  golden_food(30), villagers(40), beacons(45), netherite(50), endgame(60).
- Барьер: 650 → 1250 (день 11) → 2500 (день 21) → +100/день с 31-го (до 15000).
- Рецепты: `limited_crafting` по конфигу, поэтапная выдача/снятие через Bukkit API
  (`Player#discoverRecipes` / `undiscoverRecipes`) — без спама в чат и без
  `Unknown recipe`. Рецепты, которых нет на сервере, пропускаются с записью в лог.
- Запреты по конфигу: броня/элитра/инструменты, золотая еда, маяки, тотемы,
  измерения, торговля с жителями. Вещи выбрасываются на землю с сохранением
  чар; за инструменты — `mining_fatigue` + `weakness`.
- Возврат из запрещённого измерения: телепорт на свои координаты (из Незера ×8,
  из Энда 1:1), зажатые в мировой барьер, на самый высокий блок; на 1 секунду
  выдаются Resistance 255 и Blindness.
- Стартовые Спешка I + Скорость I (дни 0–4 по умолчанию), случайный бафф на
  10 минут при переходе на поздние фазы.
- Сложность мобов: день 10+ скорость, 25+ резист/сила, криперы 20% заряженные,
  50+ дракон 400 HP / иссушитель 600 HP + резист.
- Кровавая луна: каждая N-я ночь, гроза, блок сна, снятие невидимости, аура
  мобов, криперы 70% → зомби, спавн в темноте (свет ≤ 8), анти-отсидка в
  помещении (darkness + hunger + зомби с деревянным мечом), глубина Y<40 /
  высота Y>120 (векс/фантом), награда на рассвете.
- Два боссбара: основной (фаза + день) и предупреждение о Кровавой луне
  накануне. Личное скрытие — `/xmh bar`.
- Меню `/xmh` с кликабельными кнопками, статистикой смертей/КЛ и админ-панелью.
- **Энд (1.1.0):**
  - одна рабочая крепость (2000–3500... по конфигу 5000–8000 блоков от спавна):
    око и `/locate structure stronghold` ведут только к ней; у всех остальных
    крепостей портал ломается при подгрузке чанков (выбивается одна рамка);
  - капризные ока: шанс поломки, недолёт к крепости, визуальная молния с
    лёгким уроном и Свечением на 10 сек;
  - жемчуг Энда только с эндерменов (из бартера пиглинов убран), шанс
    зависит от Looting;
  - спавнеры блейзов: нельзя ставить блоки рядом, взрывы гастов не ломают
    крепость/спавнеры, рядом по шансу спавнятся 1–2 гаста;
  - портал: пул предметов, клик оком по рамке списывает ресурсы, ItemDisplay
    (левитация по синусоиде + поворот на игрока) и TextDisplay над рамкой;
  - награда за рамку — случайный бафф на 24 ч реального времени (одинаковые
    складываются), за каждые 2 рамки — навсегда +1 сердце;
  - с 100-го дня каждые 50 дней портал гаснет и 1–4 рамки сбрасываются;
  - защита: ломать портал/рамки/спавнер комнаты нельзя (регенерация,
    визуальный взрыв, проклятие 6 ч и запрет входа в Энд);
  - внешние острова Энда закрыты до 80-го дня (шлюзы + отталкивание за 450);
  - прочность щита при блоке атаки дракона тратится не чаще раза в ~1.8 сек;
  - спасение из пустоты Энда: 2 жемчуга → Левитация V, затем Плавное падение
    и +1..3 сердца навсегда;
  - `/xmh egg` — хранитель яйца дракона получает бесконечные Спешку II и
    Скорость I.

## Сборка

```bash
TC=/path/to/toolchain ./build.sh
```

Ожидает `$TC/jdk-25*/bin/javac` и `$TC/lib/*.jar` (см. корневой README).
Результат — `BuiltPlugins/xmusya-hard-1.1.8.jar`.

## Исходники

| Файл | Назначение |
|---|---|
| `XmusyaHard.java` | главный класс: тики, дни, фазы, барьер, КЛ, мобы, боссбары, команды |
| `PhaseCfg.java` | модель фазы из конфига + значения по умолчанию |
| `Phases.java` | таблица фаз, списки рецептов и материалов |
| `Restrictions.java` | броня/инструменты/предметы/измерения/сон |
| `Menu.java` | меню `/xmh` |
| `Msg.java` | сообщения/звуки (Adventure) |
| `EndCfg.java` | настройки секции `end:` |
| `EndState.java` | состояние энд-механик (`end-state.yml`) |
| `EndManager.java` | крепость, ока, жемчуг, спавнеры, пустота, яйцо, дракон |
| `EndPortal.java` | рамки, пул предметов, дисплеи, награды, цикл, защита |
