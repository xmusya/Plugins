# xmusya-hard

Хардкор с прогрессией по игровым дням — плагин-порт одноимённого датапака.
Paper/Leaf **Minecraft 26.3** (для сборки нужен JDK 25).

Готовый файл: [`BuiltPlugins/xmusya-hard-1.1.10.jar`](BuiltPlugins/xmusya-hard-1.1.10.jar)

---

## Установка

1. Удалить старый датапак `<мир>/datapacks/xmusya-hard 26.3.zip`
   (иначе пак и плагин дублируют эффекты).
2. Убрать из `plugins/` старые jar-ы `xmusya-hard-*` и положить новый.
3. Удалить датапак «все рецепты», если он есть — он ломает фазовую выдачу рецептов.
4. **Полностью перезапустить сервер** (не `/reload`).
5. Бота(ов) исключить из проверок: `/tag <ник_бота> add bot`.
6. Открыть меню: `/xmh`.

> Если мир уже игрался и сервер «пересоздали» (новый `world` при старых
> `plugins/xmusya-hard/*.yml`), плагин сам определит вайп и сбросит прогресс,
> Кровавую луну и энд-состояние (см. «Вайп мира» ниже).

## Команды

| Команда | Права | Что делает |
|---|---|---|
| `/xmh` | все | Меню: фаза, день, статистика, кнопки |
| `/xmh bar` | все | Личный тумблер боссбара (то же, что тег `hide_bossbar`) |
| `/xmh egg` | все | Привязать яйцо дракона (нужно держать в инвентаре) |
| `/xmh effect give <эффект\|hearts> <ник>` | все | Передать свой **позитивный** эффект другому игроку или отдать бонусное сердце |
| `/xmh skip` | op | Пропустить один игровой день |
| `/xmh reset` | op | Полный сброс: день 0, фаза wood, барьер 650, энд-механики, эффекты игроков |
| `/xmh pause` / `/xmh resume` | op | Пауза/продолжение времени мира и фаз |
| `/xmh bm start\|stop\|pause\|resume` | op | Управление Кровавой луной |
| `/xmh phase <name>` | op | Установить фазу вручную |
| `/xmh end status` | op | Крепость и рамки портала |
| `/xmh end locate` | op | Заново найти крепость |
| `/xmh end scan` | op | Пересканировать комнату портала (и починить выбитые рамки) |
| `/xmh end reset` | op | Сбросить рамки портала и пересканировать |
| `/xmh reload` | op | Перечитать `config.yml` на живом сервере |

Фазы: `wood, stone, iron, diamond, nether, golden_food, villagers, beacons,
netherite, endgame`.

Право `xmusyahard.admin` (по умолчанию — op) открывает админ-панель в меню.
Координаты крепости в `/xmh` видят только админы, остальным показывается
«найдена» / «ещё не найдена».

### Передача эффектов

```
/xmh effect give haste Pasha
/xmh effect give hearts Pasha
```

- Эффект **снимается у тебя** и появляется у другого игрока (тот же уровень и
  остаток времени). Передавать можно только положительные: `speed`, `haste`,
  `strength`, `jump_boost`, `regeneration`, `resistance`, `fire_resistance`,
  `water_breathing`, `invisibility`, `night_vision`, `health_boost`,
  `absorption`, `saturation`, `luck`, `slow_falling`, `conduit_power`,
  `dolphins_grace`, `hero_of_the_village`.
- Отрицательные (`poison`, `hunger`, `weakness`, `slowness`, `mining_fatigue`,
  `wither`, `nausea`, `blindness`, `darkness`, `unluck`, `levitation` и т.п.)
  передать нельзя.
- `hearts` — передать одно бонусное сердце (их дают за рамки портала).

## Прогрессия и барьер

- Дни считаются **по мировому времени** (`World#getFullTime`), поэтому учитываются
  сон, `/time set`, `/xmh skip` и паузы. Своих счётчиков плагин не ведёт.
- Пауза (`/xmh pause`) ставит `advance_time false`, `/xmh skip` и установка фазы
  двигают мировое время.
- Фазы по умолчанию: wood(0), stone(1), iron(5), diamond(10), nether(25),
  golden_food(30), villagers(40), beacons(45), netherite(50), endgame(60).
- Барьер:
  - 650 на старте;
  - 1250 в день 11, 2500 в день 21;
  - дальше +`border.daily` (по умолчанию 100) каждый день;
  - при переходе на новую фазу применяется её `border`, если он больше текущего;
  - последняя фаза `endgame`: **50000** (= 25 000 полных блоков) и
    **+1500 каждый день** (`phases.endgame.daily-border: 1500`).
- Геймрулы и барьер применяются **во всех мирах** (оверворлд, Незер, Энд):
  геймрулы — через `execute in <измерение> run gamerule ...`, барьер — через
  `WorldBorder` каждого мира.
- Авто-пауза через 30 сек без живых игроков.

## Конфиг

`plugins/xmusya-hard/config.yml`, читается при старте и по `/xmh reload`.
Все значения по умолчанию встроены в плагин — старый конфиг тоже работает.

### Глобальные секции

```yaml
border:
  start: 650
  mid1: 1250
  mid2: 2500
  daily: 100          # прирост барьера каждый день (если у фазы нет daily-border)
  max: 100000         # потолок барьера

bloodmoon:
  interval: 10        # каждая N-я ночь — Кровавая луна
  mob-strength: 0     # amplifier: 0 = Сила I, 1 = II, -1 = не выдавать
  mob-speed: 0

starter-buffs-until-day: 4   # Спешка I + Скорость I до этого дня включительно
```

### Фаза (`phases.<key>`)

| Ключ | Смысл |
|---|---|
| `day` | день, с которого начинается фаза |
| `border` | размер барьера при переходе на фазу |
| `daily-border` | прирост барьера каждый день на этой фазе (0 = общий `border.daily`) |
| `name` / `short-name` | названия в чате/меню и в боссбаре |
| `limited-crafting` | геймрул `limited_crafting` |
| `natural-regeneration` | геймрул `natural_health_regeneration` |
| `trade` | разрешена ли торговля с жителями |
| `dimensions` | `overworld`, `nether`, `end` |
| `forbidden-armor` | броня, которую нельзя носить (выбрасывается) |
| `forbidden-tools` | инструменты/оружие (дают `mining_fatigue` + `weakness`) |
| `forbidden-items` | предметы, выбрасываемые из инвентаря |
| `recipes` | рецепты, открывающиеся на этой фазе (дальше не отбираются) |

В `forbidden-armor`/`forbidden-tools` можно писать группы:
`iron`, `golden`, `diamond`, `netherite`, `stone`, `elytra` —
или точный id (`minecraft:turtle_helmet`, `minecraft:trident`).
Неизвестный id → предупреждение в лог, фаза грузится без него.

### Секция `end:` — энд-механики

```yaml
end:
  enabled: true

  stronghold:
    # true = одна рабочая крепость, у остальных портал ломается
    enabled: true
    min-radius: 0          # 0 = без минимального радиуса (ближайшая крепость)
    max-radius: 8000
    disable-other-portals: true
    # На время ПЕРВОГО поиска крепости барьер расширяется до этого размера,
    # затем возвращается (0 = не трогать)
    search-border-size: 50000
    scan-radius-chunks: 8
    scan-y-min: -64
    scan-y-max: 128
    scan-chunks-per-tick: 8

  eyes:
    break-chance: 0.20     # шанс, что око разобьётся
    flight-ticks: 30
    lightning-damage: 4.0
    lightning-radius: 4.0
    glow-seconds: 10
    cooldown-ms: 400
    break-sound: "entity.lightning_bolt.thunder"   # "" = без звука
    break-sound-volume: 1.0
    break-sound-pitch: 1.0

  pearls:
    enderman-chance: 0.10            # 10% без Looting
    enderman-chance-looting: 0.20    # 20% с Looting III
    remove-from-barter: true

  blaze:
    no-build-radius: 12
    protect-explosions: true
    ghast-chance: 0.15
    ghast-max: 2
    ghast-radius: 24

  portal:
    frames: 12
    buff-hours: 24
    hearts-per-frames: 2
    display-interval-ticks: 2
    display-view-range: 24
    items:                 # пул предметов для рамок
      - { material: minecraft:iron_ingot, name: "Железо", amount: 16, max-per-portal: 3 }
      # ...

  cycle:
    start-day: 100
    interval-days: 50
    reset-min: 1
    reset-max: 4

  protection:
    curse-hours: 6
    end-ban-hours: 6

  outer-islands:
    unlock-day: 80
    max-distance: 450

  dragon:
    shield-cooldown-ms: 1800

  void:
    # Спасение из пустоты Энда (Y < min-y) при наличии жемчуга
    min-y: 0
    pearls: 2
    levitation-seconds: 10
    # Уровень = значение + 1: 14 = Левитация XV
    levitation-amplifier: 14
    # Сердца: -1 = отнимает 1 сердце, 0 = не трогать, +N = даёт N
    hearts: -1
    slow-falling-seconds: 15
    slow-falling-amplifier: 0     # 0 = Плавное падение I

  egg:
    haste-amplifier: 1
    speed-amplifier: 0
```

Если секции `end:` нет — берутся эти же значения из кода.

## Что реализовано

### База
- Честный счётчик дней по мировому времени (сон, `/time set`, паузы).
- 10 фаз с запретами (броня, инструменты, предметы, измерения, торговля),
  геймрулами и рецептами.
- Рецепты выдаются/снимаются через Bukkit API (`Player#discoverRecipes` /
  `undiscoverRecipes`) — без спама в чат и без `Unknown recipe`.
- Сложность мобов по дням: 10+ скорость, 25+ резист/сила, криперы 20%
  заряженные, 50+ дракон 400 HP / иссушитель 600 HP + резист.
- Стартовые Спешка I + Скорость I (дни 0–4), случайный бафф на 10 минут при
  переходе на поздние фазы.
- Два боссбара: основной (фаза + день) и предупреждение о Кровавой луне
  накануне. Личное скрытие — `/xmh bar`.
- Возврат из запрещённого измерения: телепорт на свои координаты (из Незера ×8,
  из Энда 1:1), зажатые в мировой барьер, на самый высокий блок; на 1 секунду
  выдаются Resistance 255 и Blindness.

### Кровавая луна
- Каждая N-я ночь, гроза, блок сна, снятие невидимости, аура мобов,
  криперы 70% → зомби.
- Спавн в темноте (свет ≤ 8), анти-отсидка в помещении (darkness + hunger +
  зомби с деревянным мечом).
- **На глубине Y<40 — вексы**, на высоте — **фантомы на 10–15 блоков выше
  игрока**.
- Награда на рассвете.

### Энд
- **Одна рабочая крепость** (`end.stronghold.enabled: true`): око и
  `/locate structure stronghold` ведут только к ней. В остальных крепостях
  портал ломается — выбивается одна рамка, гасятся глаза. Чужие порталы
  проверяются и при подгрузке чанков, и раз в 10 секунд в радиусе 100 блоков
  от игроков.
- **Авто-скан портала**: раз в 5 секунд проверяется куб ±100 блоков по X/Y/Z вокруг
  портала; если внутри есть игрок — плагин чинит выбитые рамки и при неполном
  наборе пересканирует комнату (то же, что `/xmh end scan`).
- **В чужие (сломанные) порталы нельзя вставлять око** — «Этот портал сломан».
- Капризные ока: шанс поломки, визуальная молния с лёгким уроном, Свечение на
  10 сек, настраиваемый звук (по умолчанию гром).
- Жемчуг Энда только с эндерменов (из бартера пиглинов убран), 10% без чар,
  20% с Looting III.
- Спавнеры блейзов: нельзя ставить блоки рядом, взрывы гастов не ломают
  крепость/спавнеры, рядом по шансу спавнятся 1–2 гаста.
- **Портал**: 12 рамок, пул предметов (железо, золото, алмазы, незерит,
  звезда Незера…), клик оком по рамке списывает ресурсы + само око.
  Над рамками — крупный ItemDisplay (левитация + поворот на игрока) и текст
  только с количеством (`×16`), у активированной — `✔`.
  Рамки собираются из соседних чанков (портал 3×3 часто пересекает границу
  чанка). Портал открывается плоским слоем 3×3.
- Награда за рамку — случайный бафф на 24 ч реального времени (одинаковые
  складываются), за каждые 2 рамки — навсегда +1 сердце.
- С 100-го дня каждые 50 дней портал гаснет и 1–4 рамки сбрасываются.
- Защита: ломать портал/рамки/спавнер комнаты нельзя (регенерация, визуальный
  взрыв, проклятие 6 ч и запрет входа в Энд); воду/лаву рядом лить нельзя.
- Внешние острова Энда закрыты до 80-го дня (шлюзы + отталкивание за 450).
- Прочность щита при блоке атаки дракона тратится не чаще раза в ~1.8 сек.
- **Пустота Энда** (Y < 0) при ≥2 жемчуга: Левитация (уровень и время из
  конфига), затем Плавное падение; сердца настраиваются (`hearts: -1` —
  отнимает 1 сердце, `0` — не трогать, `+N` — даёт N). Макс. здоровье не
  опускается ниже 2 HP.
- `/xmh egg` — хранитель яйца дракона получает бесконечные Спешку II и
  Скорость I.

### Вайп мира
В `state.yml` и `end-state.yml` пишется UID оверворлда. Если он не совпал
(мир пересоздали) — прогресс, фаза, Кровавая луна, энд-состояние, баффы,
сердца и проклятия сбрасываются. Дополнительно есть проверка «состояние
опережает мир» (сохранённый день больше дня в мире → сброс).
`/xmh reset` полностью чистит энд-механики и снимает все эффекты с игроков.

## Сборка

```bash
TC=/path/to/toolchain ./build.sh
```

Скрипт ожидает `$TC/jdk-25*/bin/javac` и `$TC/lib/*.jar` (см. корневой README).
Результат — `BuiltPlugins/xmusya-hard-<версия>.jar`.
