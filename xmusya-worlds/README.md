# xmusya-worlds

Мультимировой хаб-плагин для Paper/Leaf **26.3**: отдельные миры, порталы-области,
общий Энд и память позиций игрока по мирам. Без Gradle/Maven.

> Вдохновлено сервером **Pepeland** — идея хаб-мира с порталами в разные миры.

## Что делает

- Создаёт при старте набор миров (папки `world_*`, хаб и т.д.).
- **Кастомные измерения из датапака** (companion-пак `xmusya-worlds.zip` ставится
  в `world/datapacks`): `xmusya:world_cave` (пещеры) и `xmusya:world_islands`
  (острова). В 26.x датапаки глобальны, поэтому cave/islands сделаны отдельными
  измерениями, а не тотальными паками (иначе ломается выживание).
- **Порталы-области**: в мире-хабе заданы прямоугольные зоны (2 угла, внутренняя
  часть). Когда игрок входит в зону — через `portal-delay-ticks` (0.2с) и со
  слепотой на 1с его телепортирует в целевой мир.
- **Общий Энд**: вход в Энд из любого мира ведёт в один общий Энд-мир; выход
  возвращает в мир-источник на позицию игрока.
- **Память позиций** (`players.yml`): игрок возвращается в мир туда, где вышел.
- **Респавн в мире смерти** (`respawn.in-death-world`), **приключение только в
  хабе** (`hub.adventure-mode`), **телепорт на спавн при падении в пустоту**
  (`void.teleport-to-spawn`).
- Команды `/hub` (возврат в хаб) и `/worlds reload|list|tp|spawn|setspawn|datapacks|reset`.

## Миры по умолчанию

| ключ      | папка          | генерация                          |
|-----------|----------------|------------------------------------|
| hub       | `xmhub`        | vanilla (уже построен), спавн 0/45/0 yaw -90 |
| survival  | `world`        | vanilla (основной мир)             |
| cave      | `world_cave`   | измерение `xmusya:world_cave` (пещеры) |
| farm      | `world_farm`   | vanilla                            |
| islands   | `world_islands`| измерение `xmusya:world_islands` (острова) |

Общий Энд: `world_the_end`.

| -> мир     | min            | max            |
|------------|----------------|----------------|
| cave       | -3,44,7        | -1,46,7        |

| islands    | -3,44,-12      | -1,46,-10      |
| survival   | 6,44,-2        | 6,46,0         |

## Конфиг

`config.yml` максимально гибкий и прокомментирован: `general.*` (задержки,
слепота, кулдауны, интервал скана), `worlds.*` (генератор/окружение/тип/спавн),
`portals.*` (регионы, сообщения, тип точки назначения, кулдаун), `end.*`,
`hub-command.*`, `respawn.*`, `void.*`. После правок — `/worlds reload`.

## Сборка

```bash
./build.sh          # тулчейн ../.toolchain, результат BuiltPlugins/xmusya-worlds-<version>.jar
```
Версия берётся из `plugin.yml`.
